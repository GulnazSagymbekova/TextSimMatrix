# Text Similarity & Plagiarism Detection Pipeline

Проект посвящен сравнительному анализу текстового сходства на базе датасета **AG News** с использованием классических методов (TF-IDF), векторных представлений слов (Word2Vec) и современных языковых моделей (Sentence-Transformers / SBERT).

## Основные возможности
* **TF-IDF + Косинусное сходство**: Базовый статистический подход для оценки пересечения ключевых слов.
* **Word2Vec (Gensim)**: Усреднение векторных представлений слов для поиска семантической близости.
* **Sentence-BERT (SBERT)**: Глубокий семантический анализ с использованием модели `all-MiniLM-L6-v2`.
* **Автоматический детектор**: Пороговая фильтрация матриц сходства для выявления похожих текстов и потенциального плагиата.
